# پروفایل عملکرد: Warcraft III (نسخهٔ قانونی کاربر)

این فایل فقط تنظیمات کانتینر است. هیچ فایل بازی یا روش دورزدن محافظت (CD/DRM) را شامل نمی‌شود.
نصب بازی باید از نسخهٔ قانونی خود کاربر (دیسک یا فروشگاه رسمی) انجام شود.

وضعیت: **تست‌نشده روی گوشی.** ترتیب زیر را به‌ترتیب امتحان کنید و نتیجه را گزارش دهید.

## تنظیمات شروع (Container)
| بخش | مقدار اول | اگر روان نبود | اگر اصلاً باز نشد |
|---|---|---|---|
| Screen size | 960x540 | همان 960x540 | 960x540 |
| Graphics driver | Turnip (فقط Adreno) یا پیش‌فرض | Vortek یا Gladio | Gladio |
| DX wrapper | DXVK | — | WineD3D |
| Box64 preset | PERFORMANCE | STABILITY | STABILITY |
| Windows version | Windows XP (اگر موجود بود) | Windows 7 | Windows 7 |
| Environment | `MESA_EXTENSION_MAX_YEAR=2003` | — | — |

اگر با 960x540 روان شد، می‌توانید به 1280x720 بروید و دوباره تست کنید.

## نکات
- برای گوشی‌های Xiaomi: محدودیت باتری را برای Gamelator خاموش کنید، اجرای خودکار را روشن کنید و اپ را در لیست برنامه‌های اخیر قفل کنید.
- درایور گرافیکی را بعد از هر تغییر، یک بار بازی را کامل ببندید و دوباره باز کنید.

## گزارش تست (لطفاً این موارد را بفرستید)
1. مدل دقیق گوشی و نسخهٔ اندروید.
2. تنظیمات استفاده‌شده (وضوح، درایور، DX wrapper، Box64 preset).
3. آیا بازی باز شد؟ مدت زمان باز شدن منو.
4. FPS یا لگ تقریبی در منو و در یک نقشهٔ کامل.
5. کرش یا پیام خطا (عکس صفحه کمک می‌کند).
